# Telegram · GREEN-API — текстовый чат

React + TypeScript + Vite. Приложение отправляет и получает текстовые сообщения через GREEN-API Telegram.

## Почему Telegram

Исходное ТЗ предполагает MAX, но разрешает использовать Telegram или WhatsApp, если реализация MAX недоступна. В проекте выбран Telegram через GREEN-API.

## Где взять данные GREEN-API

1. Зарегистрируйтесь в GREEN-API Console.
2. Создайте Telegram instance.
3. Авторизуйте Telegram-аккаунт в созданном инстансе.
4. В карточке инстанса возьмите `apiUrl`, `idInstance` и `apiTokenInstance` для экрана подключения.
5. В настройках уведомлений включите входящие сообщения и оставьте `webhookUrl` пустым для работы `ReceiveNotification`.

## Запуск

```bash

```

```bash
npm run build

```

## Сценарий проверки

1. Введите параметры подключения. Приложение проверит авторизацию через `GetStateInstance`.
2. Введите номер телефона получателя. Приложение вызовет `CheckAccount`.
3. После получения `chatId` создастся локальный чат.
4. Отправьте текстовое сообщение через `SendMessage`.
5. Получатель отвечает в Telegram. Ответ приходит через `ReceiveNotification`, появляется в интерфейсе, затем уведомление удаляется через `DeleteNotification`.

## Ограничения

- Поддерживаются только текстовые сообщения; группы не поддерживаются.
- Чаты и история сообщений хранятся только в памяти React и не восстанавливаются после обновления страницы.
- Параметры подключения не сохраняются.
- На тарифе Telegram Developer ограничено количество доступных чатов.

## Структура

- `src/pages` — форма подключения и экран чата.
- `src/components` — общие визуальные элементы.
- `src/types` — типы чатов, сообщений и ответов API.
- `src/services/greenApi.ts` — HTTP-запросы к GREEN-API.
- `src/hooks` — подключение, состояние чатов, отправка и последовательный polling уведомлений.
- `src/state/chatReducer.ts` — reducer для чатов и сообщений.
- `src/App.tsx` — переключение экранов и хранение параметров подключения в памяти.
- `src/styles.css` — стили и адаптивная верстка.
