# Telegram · GREEN-API — текстовый чат

React + TypeScript + Vite. Приложение подключается к инстансу GREEN-API для Telegram, отправляет текстовые сообщения и получает входящие уведомления. Параметры подключения хранятся только в памяти React и исчезают после обновления страницы или выхода.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Структура

- `src/pages` — форма подключения и экран чата.
- `src/components` — общие визуальные элементы.
- `src/types` — типы чатов, сообщений и ответов API.
- `src/services/greenApi.ts` — все HTTP-запросы к GREEN-API.
- `src/hooks` — подключение, состояние чатов, отправка и последовательный polling уведомлений.
- `src/state/chatReducer.ts` — чистый reducer для чатов и сообщений.
- `src/App.tsx` — переключение экранов и хранение параметров подключения в памяти.
- `src/styles.css` — стили и адаптивная верстка.

Новый личный чат создаётся по номеру телефона: приложение один раз вызывает `CheckAccount`, получает числовой Telegram `chatId` и использует только его для отправки и связывания сообщений. Если аккаунт не найден, чат не создаётся. Групповые чаты в этом задании не поддерживаются.

Для приёма входящих сообщений в настройках инстанса должен быть включён `incomingWebhook`, а поле `webhookUrl` должно быть пустым, чтобы работал `ReceiveNotification`.

История переписки с сервера не загружается: после обновления страницы локальный список чатов и сообщений начинается заново.
